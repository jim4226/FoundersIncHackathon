Why three sensors

How the three inputs divide the work

Gesture says what the verdict is. Attention says what it applies to. Effort says whether it binds.

An approve while focused promotes the design. The same approve while diffuse is recorded but held for review. That distinction is invisible to a camera and trivial for the headband — which is the cleanest statement of why the EEG earns its place on the desk. Watch the demo for half a minute and it makes that argument twice.

The pieces

What's built

Every page on this host is driven by a simulated bench, and says so. The real thing is a Python process on a laptop with a headband and two cameras attached, which no static host can run — so when nothing answers, the pages fall back to a browser-side simulator that speaks the identical event stream. That fallback is the same design rule the backend was built on: nothing downstream knows what produced its events.

About the live one

The bench itself is hardware.

A Muse headband reading effort and attention, an overhead camera or a paired phone watching the desk, and a laptop holding it together over WebSockets. A website cannot run any of that — so everything on this host is the simulator, honestly labelled. A simulated effort score presented as a measured one would be the single dishonest thing in this project.

On your own machine

Run the real one

The same files this site serves, driving real hardware. With a Muse: EEG_SOURCE=osc for Mind Monitor on a phone, or EEG_SOURCE=brainflow for native BLE.

# the bench: simulated subject, no hardware needed
pip install -r requirements.txt
python -m backend.server --https

# scan the QR on the control view to use your phone as the desk camera,
# or run the overhead webcam service instead
python desk/desk_server.py --synthetic

# votes, with or without a camera
python gesture/gesture_server.py
python gesture/mock_votes.py
Credibility

What we deliberately did not build

This list is an asset, not an apology — overclaiming is how EEG demos die.

  • No frontal-theta "focus score." The workload literature measures frontal midline theta at Fz/FCz. Muse has no midline electrode and references to FPz, which cancels those potentials rather than attenuating them — and the blink artifact sits in the same band 50× larger. The meter would be a blink counter in a lab coat.
  • No theta/beta "attention" metric. Discredited in its own clinical literature, and on dry electrodes the beta band is dominated by jaw muscle.
  • No error-related potentials. The ERN comes from anterior cingulate and peaks at FCz. We have no central electrode. Structurally unmeasurable here.
  • Nothing that "reads your thoughts." Four dry electrodes, two of which are functionally EOG sensors.
