The workbench knows what you're looking at, and how hard you're thinking.

Physical products get built in a mess. CAD lives in two different packages, the STEP files are on someone's desktop, the feedback is in email, and two weeks later nobody remembers why the wall thickness changed. Software solved this with git and then handed it to agents. Hardware never got either.

Bench is the missing input layer. A camera watches the desk and draws on it. An EEG headband watches the person. Together they turn what happens at a physical workbench into a project history an agent can actually reason over.

These are live pages, driven by a simulated bench. The real thing is a Python process on a laptop with a headband and two cameras attached, which no static host can run — so when nothing answers, the pages fall back to a browser-side simulator that speaks the identical event stream. That fallback is the same design rule the backend was built on: nothing downstream knows what produced its events. Run python -m backend.server --https locally and the same files drive real hardware.

How the three inputs divide the work

Gesture says what the verdict is. Attention says what it applies to. Effort says whether it binds.

An approve while focused promotes the design. The same approve while diffuse is recorded but held for review. That distinction is invisible to a camera and trivial for the headband — which is the cleanest statement of why the EEG earns its place on the desk. Watch the control view for half a minute and it makes that argument twice.

Gesture 👍 / 👎

MediaPipe thumbs-up and thumbs-down over a webcam, arriving as a vote. A verdict with no subject attached.

Attention the referent

Horizontal EOG catches the switch, alpha lateralisation holds it. Every quantity is a contrast between two electrodes, so there is no calibration step.

Effort the gate

Blink rate, alpha and stillness. Below threshold the agent asks a question instead of acting, and destructive operations lock.

What's built

Operator state
Muse EEG — effort score, left/right attention, and a deliberate double-blink flag that overrides the meter.

Desk vision
Background subtraction against an empty-desk reference. No model, no labels, no GPU — and it does not care what you put down.
built
Phone camera
Scan a QR code and the phone becomes the desk camera. Same detector as the webcam path, so nothing downstream can tell which one it has.
built
Gesture
Thumbs up/down over a WebSocket, routed onto whatever the operator is attending to and gated on effort.

Run the real one

# the bench: simulated subject, no hardware needed
pip install -r requirements.txt
python -m backend.server --https

# scan the QR on the control view to use your phone as the desk camera,
# or run the overhead webcam service instead
python desk/desk_server.py --synthetic

# votes, with or without a camera
python gesture/gesture_server.py
python gesture/mock_votes.py

With a real headband: EEG_SOURCE=osc python -m backend.server for Mind Monitor on a phone, or EEG_SOURCE=brainflow for native BLE.

What we deliberately did not build

  • No frontal-theta "focus score." The workload literature measures frontal midline theta at Fz/FCz. Muse has no midline electrode and references to FPz, which cancels those potentials rather than attenuating them — and the blink artifact sits in the same band 50× larger. The meter would be a blink counter in a lab coat.
  • No theta/beta "attention" metric. Discredited in its own clinical literature, and on dry electrodes the beta band is dominated by jaw muscle.
  • No error-related potentials. The ERN comes from anterior cingulate and peaks at FCz. We have no central electrode. Structurally unmeasurable here.
  • Nothing that "reads your thoughts." Four dry electrodes, two of which are functionally EOG sensors.
