What this is measured from

  • Blink rate — ocular (EOG) on AF7/AF8. ~5/min absorbed, ~26/min diffuse.
  • Alpha — cortical, 8–13 Hz at TP9/TP10. The one true brain signal here.
  • Stillness — the headband's IMU. Not a brain signal.

No frontal-theta "focus score". Muse references to FPz, which cancels frontal-midline theta, and the blink artifact is 50× larger than what's left.
